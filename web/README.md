# 党费记账软件 - Web 版

专为各级党组织设计的财务管理系统，支持凭证管理、账簿查询、报表生成等功能。

## 🚀 快速开始

### 方式一：一键启动（推荐）

**Windows 系统：**
```
双击运行：启动.bat
```

**银河麒麟 / Linux 系统：**
```bash
chmod +x 启动.sh  # 首次运行添加执行权限
./启动.sh
```

### 方式二：手动启动

```bash
# 进入项目目录
cd web

# 安装依赖（首次运行）
npm install

# 启动开发服务器
npm run dev
```

然后在浏览器中打开：http://localhost:3000

## ✨ 功能特性

| 功能 | 描述 |
|------|------|
| 科目管理 | 支持自定义会计科目，预置常用党费科目 |
| 凭证管理 | 凭证录入、编辑、删除，自动编号，借贷平衡校验 |
| 账簿查询 | 明细账、总账查询，支持按日期和科目筛选 |
| 报表管理 | 科目余额表，支持 Excel 导出 |
| 数据管理 | 自动备份、数据导入导出（JSON 格式） |
| 打印功能 | 支持凭证、账簿、报表打印 |
| 党建特色 | 红色主题配色 |

## 💾 数据存储

- **IndexedDB**：主要数据存储（浏览器内置数据库）
- **localStorage**：配置和快速备份
- **JSON 导出**：用户可手动备份到本地文件

## 📋 系统要求

- Node.js 16 或更高版本
- 现代浏览器（Chrome 90+、Edge 90+、Firefox 88+、Safari 14+）
- 支持 Windows、Linux（银河麒麟）、macOS

## 🛠️ 技术栈

- React 18 + TypeScript
- React Router 6（路由）
- Zustand（状态管理）
- Vite（构建工具）
- Tailwind CSS（样式框架）
- IndexedDB（数据存储）
- xlsx（Excel 导出）

## 🤝 操作指南

### 1. 首次使用

- 系统会自动创建预置科目（现金、银行存款、党费收入等）
- 开始录入凭证

### 2. 定期备份

- 建议定期在「系统设置」中导出数据备份
- 可开启自动备份功能

### 3. 打印报表

- 在相应页面点击「打印」按钮
- 系统会自动隐藏导航栏，只打印内容

## 📞 支持

如有问题，请检查：
1. Node.js 是否已正确安装
2. 浏览器是否为最新版本
3. 控制台是否有错误信息
